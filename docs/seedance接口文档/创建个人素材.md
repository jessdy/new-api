# 创建个人素材

## OpenAPI Specification

```yaml
openapi: 3.0.1
info:
  title: ''
  description: ''
  version: 1.0.0
paths:
  /v1/virtual-characters:
    post:
      summary: 创建个人素材
      deprecated: false
      description: >
        上传一张图片、一段视频或一段音频，创建当前用户的个人素材，供后续 Seedance
        视频请求重复引用。创建后的素材为私有素材，`source_type=volc_aigc`。


        **完整流程：准备文件 → 创建并上传素材 → 查询素材状态 → 引用素材生成视频 → 查询并获取视频。** HTTP `201`
        只表示创建和上传已受理，必须等待素材为 `active` 后再用于生成。


        本教程适用于普通个人素材，例如虚构角色、物品、场景及可用的参考视频、音频。需要登记真人肖像时，应使用“创建真人核验会话”接口，先由本人完成认证，再上传本人肖像。


        ### 1. 准备鉴权与文件


        服务地址为 `https://susciyuan.com`。下文路径均相对于该地址，`{character_id}` 和 `{task_id}`
        需替换为实际返回值。全部 API 请求携带 `Authorization: Bearer <API_KEY>`，使用同一用户的 API Key
        创建、查询和引用个人素材。


        可先调用 `GET /v1/virtual-characters?scope=private&source_type=volc_aigc`
        查看个人素材列表，读取 `data.used` 和 `data.limit` 了解个人素材占用量与额度。


        每次创建上传一个文件，类型和大小限制如下：


        | 素材类型 `asset_type` | 文件格式 | 最大大小 |

        |---|---|---|

        | `Image` | jpg / jpeg / png / webp / gif / heic | 30MB |

        | `Video` | mp4 / mov | 50MB |

        | `Audio` | mp3 / wav | 15MB |


        文件扩展名需与所选类型匹配。这些是素材上传限制，生成时还需满足所选模型对参考媒体的数量、时长和组合要求；素材入库成功不代表可以用于任意模型或任意组合。


        ### 2. 创建个人素材并上传文件


        调用本接口 `POST /v1/virtual-characters`，请求体使用 `multipart/form-data`：


        - `file`：必填，素材文件本身。

        - `name`：必填，素材名称。

        - `asset_type`：可选，取 `Image`、`Video` 或 `Audio`；省略时按文件扩展名推断。

        - `description`：可选，素材说明。

        - `tags`：可选，JSON 数组字符串或逗号分隔的标签，例如 `["角色","演示"]`。


        由 HTTP 客户端的表单上传功能生成 multipart boundary 和对应的 `Content-Type`，不要把文件作为 JSON
        字段或普通文件路径字符串发送。Bash/cURL 示例（`API_KEY` 为本地环境变量）：


        ```bash

        curl --request POST \
          "https://susciyuan.com/v1/virtual-characters" \
          --header "Authorization: Bearer ${API_KEY}" \
          --form "name=我的机器人角色" \
          --form "description=视频演示使用的虚构机器人" \
          --form 'tags=["角色","演示"]' \
          --form "asset_type=Image" \
          --form "file=@./robot.png"
        ```


        上传视频时，将类型改为 `Video`、文件改为例如 `file=@./reference.mp4`；上传音频时使用 `Audio` 和例如
        `file=@./reference.wav`。


        HTTP `201` 后保存 `data.id`，它就是后续使用的数字 `character_id`。保存 `data.asset_type`
        以便选择对应引用格式；`data.provider_asset_id` 是 `asset://` 引用所需的素材标识，应在素材生效后确认非空。


        **个人素材的创建和上传在本次请求内完成，不需要再调用 `/{id}/asset`。**
        该上传接口用于真人核验后的肖像上传。本接口也不需要先创建核验会话或获取认证二维码。


        ### 3. 等待素材生效


        调用 `GET /v1/virtual-characters/{character_id}`，检查响应 `data.status`：


        - `creating`：仍在处理，可从约 5 秒间隔开始轮询，等待较久时适当增加间隔。

        - `active`：素材已生效；同时确认 `data.provider_asset_id` 非空，再用于视频生成。

        - `failed`、`blocked`、`offline`：当前不可用于生成，查看 `data.last_error` 后排查。

        - `deleting`：素材正在删除，不再提交新的引用请求。


        个人素材通过详情接口查询状态，不要调用真人专属的 `POST
        /v1/virtual-characters/{id}/sync`。上传超时或连接中断时，先查询素材列表确认是否已创建，避免反复上传产生重复素材。


        ### 4. 使用单个素材生成视频


        只需要引用一个图片素材时，可直接使用 `character_id`。调用 `POST /v1/videos`，请求头设置
        `Content-Type: application/json`，例如：


        ```json

        {
          "model": "AP Seedance-2.5 标准版",
          "character_id": 123,
          "prompt": "参考机器人在花园里行走，保持角色外观一致，镜头缓慢跟随。",
          "resolution": "480p",
          "ratio": "16:9",
          "duration": 4,
          "generate_audio": false
        }

        ```


        将 `123` 替换为刚才保存的 `data.id`，在 JSON 中保持数字类型。视频素材也可按所选模型支持情况使用单个
        `character_id` 引用。使用此字段时，不要同时提供其他图片、视频、音频参考字段，否则会发生引用冲突。


        ### 5. 使用多个素材或音频参考


        需要组合素材时，改用 `content` 数组中的 `asset://` 引用，不再传
        `character_id`。每个素材都需先创建并生效，然后按素材类型填写：


        | 素材类型 | `type` | URL 字段 | `role` |

        |---|---|---|---|

        | 图片 | `image_url` | `image_url.url` | `reference_image` |

        | 视频 | `video_url` | `video_url.url` | `reference_video` |

        | 音频 | `audio_url` | `audio_url.url` | `reference_audio` |


        URL 写为 `asset://{provider_asset_id}`，其中标识来自素材详情的
        `data.provider_asset_id`。不要填写角色数字 ID、素材组 ID 或本地文件路径，也不要重复添加 `asset://`
        前缀。


        以下示例组合一个图片素材和一个音频素材；请将两个占位标识分别替换为已生效素材的 `provider_asset_id`：


        ```json

        {
          "model": "AP Seedance-2.5 标准版",
          "content": [
            { "type": "text", "text": "参考机器人在舞台上随参考音频的节奏轻轻摆动。" },
            {
              "type": "image_url",
              "image_url": { "url": "asset://替换为图片素材的provider_asset_id" },
              "role": "reference_image"
            },
            {
              "type": "audio_url",
              "audio_url": { "url": "asset://替换为音频素材的provider_asset_id" },
              "role": "reference_audio"
            }
          ],
          "resolution": "480p",
          "ratio": "16:9",
          "duration": 4,
          "generate_audio": true
        }

        ```


        音频参考建议与图片或视频参考组合使用，并遵守所选模型的输入约束；不要将仅音频的 `character_id`
        示例理解为所有模型均支持。所有个人素材必须属于当前调用用户，知道其他用户的素材 ID 不代表有权引用。


        ### 6. 查询与获取生成结果


        `POST /v1/videos` 返回 HTTP `202` 后，保存响应顶层 `id` 为 `{task_id}`，调用 `GET
        /v1/videos/{task_id}` 查询。注意素材接口的 ID 在 `data.id`，视频任务 ID 在响应顶层，两者不能混用。


        - `queued`、`in_progress`：继续轮询，不要重复创建同一视频请求。

        - `completed`：读取 `metadata.url`，或通过带 Bearer 鉴权的 `GET
        /v1/videos/{task_id}/content` 获取视频。

        - `failed`：读取任务错误信息，停止轮询并排查。


        也可以使用官方兼容的 `POST /api/v3/contents/generations/tasks`，并通过对应的 `GET
        /api/v3/contents/generations/tasks/{task_id}` 查询；创建成功码为 `200`，生成成功状态为
        `succeeded`，结果地址为 `content.video_url`。用哪个协议创建，就用对应协议查询。


        模型、可用规格和价格以账号实际可用项及 `GET /api/pricing` 为准。上传素材和提交视频是两个独立步骤，生成视频会按当前价格计费。


        ### 7. 删除素材与常见问题


        不再需要的个人素材可调用 `DELETE /v1/virtual-characters/{character_id}` 删除。返回
        `data.status=deleting` 表示正在清理，不保证立即完成；删除后不要继续提交新的素材引用。


        - `missing_file` / `invalid_file` / `invalid_upload`：检查文件字段名、类型、大小及
        multipart 请求格式。

        - `invalid_metadata`：检查必填名称及其他元数据是否符合下方字段约束。

        - `limit_reached` / `account_asset_cap_reached`：素材额度已满，清理不再需要的素材或联系管理员。

        - `virtual_disabled`：个人素材功能当前不可用，联系管理员。

        - `character_reference_conflict`：同时传了 `character_id`
        和其他参考媒体，改为单素材引用或统一使用 `content`。

        - 创建返回成功但暂时不能生成：先确认素材为 `active`，且 `provider_asset_id` 非空。

        - 素材已生效但创建视频报错：保留请求时间、模型、规格与错误响应排查，不要因此重复上传素材。
